# Gtracking - 智能运单轨迹查询助手

Gtracking 是一款专为跨境电商与物流追踪打造的**高端智能运单轨迹查询助手**。它拥有极具未来感与科技感的玻璃拟态（Glassmorphism）双主题界面，完美集成了 **17TRACK 实事运单状态追踪**，并结合后台 **Playwright 异步爬虫**与**内存缓存系统**，为您提供闪电般快速且全自动的物流状态追踪体验。

---

## 🌟 核心特性

- 🌐 **17TRACK 实时状态集成**：
  - 无缝对接 17TRACK 派送查询接口。
  - 在运单列表卡片中，运单号后方直接实时展示来自 17TRACK 的最新物流状态（如 `Delivered (7 Days) - Signed` 等），无需跳转即可一眼掌控全局。
  - 点击运单号可瞬间唤起 17TRACK 专属嵌入式动态轨迹详情弹窗，深入查看完整物流节点。

- ⚡ **无感后台异步爬虫**：
  - 基于 **Python Playwright** 实现的自动化后台抓取程序，完美绕过 Cloudflare Turnstile 验证机制。
  - 采用完全非阻塞设计，前端页面即刻加载完毕，17TRACK 轨迹状态在后台自动异步获取并实时局部刷新。

- 🚀 **超高性能内存缓存**：
  - 内置基于时间的智能缓存机制（`TRACKING_CACHE`）。
  - 对已查询的运单进行智能缓存，同一单号再次查询时**直接闪电返回**（0 毫秒延迟），极大减少重复请求与 API 负载。

- 🌓 **双维奢华视觉主题**：
  - **深色模式（Dark Mode）**：极具科技感的深蓝太空微发光玻璃卡片，专为夜间与极客开发者设计。
  - **浅色模式（Light Mode）**：温和护眼的软灰蓝背景，搭配透亮极致的纯白微阴影拟态面板，质感高端细腻。
  - **状态持久化**：采用 `LocalStorage` 自动记忆用户的主题选择，重开页面无需重复切换。

## 🛠️ 安装与快速开始

### 1. 克隆/下载项目
将项目代码下载至您的本地目录。

### 2. 安装 Python 依赖
本项目依赖 `Playwright` 及其浏览器内核来处理 17TRACK 的高强度防爬系统。
在项目目录下打开终端，执行以下命令安装依赖：

```bash
pip install playwright
playwright install chromium
```

### 3. 一键启动
在 Windows 操作系统中，您只需双击运行 **`start_web.bat`** 即可。

或者手动使用终端运行：
```bash
python server.py
```

### 4. 访问系统
服务启动后，在浏览器中打开：
👉 **[http://localhost:7000](http://localhost:7000)**

---

## ⚙️ 系统配置说明

1. 打开系统后，在左侧的 **“系统配置”** 栏中输入您的 `Admin-Token` 与完整的系统 `Cookie`。
2. 点击 **“保存配置”**，配置将自动同步并加密存储于后台服务中。
3. 在主输入框中输入运单号（多个运单换行分隔），选择查询类型，点击 **“立即查询”** 即可体验极速物流追踪。

## 🔒 隐私与安全

- **防泄漏设计**：项目自带完善的 `.gitignore` 规则，您的 `Admin-Token`、`Cookie`、本地请求日志及账密信息**绝对不会**被提交到 GitHub 等公共代码托管平台，保障物流数据与账号资产的绝对安全。

Gtracking 的设计理念遵循极简与奢华：
- **字体**：引入 Google Fonts 高端无衬线字体 `Outfit` 和 `Noto Sans SC`。
